# 🇬🇧 English Mastery Coach (Start → B2)

A state-of-the-art interactive web application built with **HTML5, Vanilla CSS3, and ES6 JavaScript**. Features a **13-Part 100-Stage Curriculum**, **8-Skill Integrated Learning Model**, **Speakometer-Style British Accent Engine**, **Dynamic Content Refresh Generators [🔄]**, **3-Step Shadowing Drill**, **60-Second Daily Challenge Mini-Game**, **10-Question Adaptive Placement Test**, and **SVG 8-Skill Radar Analytics**.

---

## 🌟 Key Features

### 1. 13-Part / 100-Stage Curriculum Roadmap
- Complete progression from **A1 Foundations** up to **B2 Speaking & Writing Mastery**.
- Interactive roadmap navigator with active stage tracking.

### 2. 8-Skill Integrated Lesson Player
- Integrates **Grammar, Vocabulary, Speaking, British Pronunciation (RP/SSB), Listening, Reading, Writing, and Communication** around every stage topic.

### 3. Dynamic Content Generators (`[🔄]` Refresh Buttons)
- Instant dynamic rotation for Grammar Examples, Vocabulary Cards, RP Target Sounds, Reading Passages, and Active Practice Sets.

### 4. Speakometer-Style British Accent Engine
- **4-Parameter RP Evaluation**: Vowel Quality & Length, Non-Rhoticity (Silent 'R'), Weak Forms & Schwa (/ə/), Syllable Stress.
- **Interactive Audio Player Bar**: Play/Pause, 0.75x/1.0x speed control, progress scrubbing, and animated 8-bar audio waveform.
- **Color-Coded Phoneme Map & Spoken Word Status Badges** (`🟢 Correct RP`, `🟡 Variant`, `🔴 Mispronounced`).
- **SVG Mouth & Tongue Positioning Diagrams**.

### 5. 3-Step Interactive Shadowing Drill
- *Listen* to native British RP reference audio &rarr; *Record* student voice &rarr; *Compare* side-by-side pitch contour and rhythm match.

### 6. 60-Second Daily Challenge Mini-Game
- Timed 5-question rapid-fire quiz with XP score awards (+250 XP) and learning streak tracking.

### 7. 10-Question Adaptive Placement Test
- Multi-skill assessment evaluating Grammar, Vocab, Reading, Listening, and RP Pronunciation for optimal stage placement.
